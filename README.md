# Fit Regression Model
The goal of this project is to find the Best Fit for a Regression Model. The user will see a prompt and has to enter the path for a .csv file that contains some data.
Then the user can choose the type of Regression Model (Linear/Ridge/Lasso). Afterwards the user can provide the size of the test part and additional parameters for the regression functions.
The resulting intercept, coefficient and r^2 score will be output. After that the users will be prompted to enter a start and end range for the result plot. 

API Reference for scikit-learn functions: https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LinearRegression.html

# How to run the Script
In order to run the script you need to run the prompt.py file.
